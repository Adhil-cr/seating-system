# 🎓 ExamCell

## Examination Hall Seating Arrangement Automation System

ExamCell is a full-stack web application and standalone desktop solution that automates examination hall seating allocation, student management, hall configuration, and report generation.

The system eliminates manual seating arrangement preparation by automatically allocating students across examination halls while enforcing hall capacities and seating constraints.
