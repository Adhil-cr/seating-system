# ExamCell

## Examination Hall Seating Arrangement Automation System

ExamCell is a web-based and standalone examination seating arrangement automation platform developed using Django.

The system automates student allocation, hall management, examination scheduling, seating generation, and report exports while reducing manual work and allocation errors.

---

## Key Features

### Authentication

- User Registration
- Login System
- Session Management

### Student Management

- CSV Upload
- Student Records
- Upload History

### Examination Management

- Exam Creation
- Subject Selection
- Session Management (AM / PM)

### Hall Management

- Hall Configuration
- Capacity Calculation

### Seating Allocation

- Automated Seat Generation
- Allocation Validation
- Hall-wise Distribution

### Reports

- PDF Export
- Excel Export

### Deployment Options

- Cloud Deployment
- Linux Standalone Application
- Windows Standalone Application
